
# Organisational Hierarchy and Department Searching

## Objective
To represent a company's organisational hierarchy using
a tree and compare Linear Search and Binary Search.

## Programs
1. tree_hierarchy.c
2. department_search.c

## Input Data
The hierarchy contains CEO, HR, Finance, IT,
Development, Testing, Frontend and Backend.

## How to Compile and Run

Compile the tree program:

gcc tree_hierarchy.c -o tree_hierarchy

Run the tree program:

./tree_hierarchy

Compile the search program:

gcc department_search.c -o department_search

Run the search program:

./department_search

On Windows, run tree_hierarchy.exe and
department_search.exe after compiling.

## Files Included
- input_data.txt
- tree_output.txt
- search_output.txt
- trace_tables.txt
- complexity_analysis.txt

## Conclusion
A tree is suitable for organisational reporting.
Binary Search is more efficient for searching a
large, sorted list of department names.
